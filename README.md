# Satyam Chaudhary - Integrating With HubSpot I Practicum

This repository is for the HubSpot Academy Integrating With HubSpot I: Foundations practicum.

## Custom Object List View

Replace the account ID and object ID in this URL after creating the custom object in the HubSpot developer test account:

https://app.hubspot.com/contacts/<test-account-id>/objects/<custom-object-id>/views/all/list

## Local setup

1. Copy `.env.example` to `.env`.
2. Add your HubSpot private app token and custom object type ID.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
